# 09. コマンド一覧

> Claude Codeを使う際に知っておくべきコマンドを一覧で整理しました。

---

## コマンドの3つの種類

Claude Codeのコマンドは大きく3つに分かれます。

| 種類 | どこで入力？ | 例 |
|------|-------------|------|
| **CLIコマンド** | ターミナル（Claude Codeの外） | `claude`, `claude --version` |
| **スラッシュコマンド** | 会話中（Claude Codeの中） | `/help`, `/compact` |
| **キーボードショートカット** | 会話中 | `Ctrl+C`, `Shift+Enter` |

---

## CLIコマンド（ターミナルで入力）

Claude Codeを起動・制御するコマンドです。ターミナルで入力します。

### 基本実行コマンド

| コマンド | 説明 | 例 |
|--------|------|------|
| `claude` | 対話モードを開始 | `claude` |
| `claude "質問"` | 質問しながら開始 | `claude "このプロジェクトを説明して"` |
| `claude -p "質問"` | 回答だけ出力して終了（自動化に便利） | `claude -p "この関数を説明して"` |
| `claude -c` | 最新の会話を引き継いで開始 | `claude -c` |
| `claude --version` または `claude -v` | インストール済みバージョンの確認 | `claude -v` |
| `claude --help` | ヘルプを表示 | `claude --help` |
| `claude update` | 最新バージョンにアップデート | `claude update` |

### モデルを指定して実行

```bash
# 特定のモデルで開始
claude --model claude-opus-5-5

# または短縮形（エイリアス）で
claude --model opus      # 最新のOpus（現在はOpus 5.5） ── すべてのプランのデフォルトモデル
claude --model sonnet    # 最新のSonnet（現在はSonnet 5.5）
claude --model haiku     # 最速・最安（現在はHaiku 5.5）
claude --model fable     # 最難関・長時間タスク向け（現在はFable 5.1、別途アクセス権限が必要）
claude --model opusplan  # 計画はOpus、実行はSonnet
```

> **2026年10月時点のモデルラインナップ**: Fable 5.1 → Opus 5.5 → Sonnet 5.5 → Haiku 5.5。4モデルすべてコンテキストウィンドウは**100万トークン**です。
> `opus`・`sonnet`などのエイリアスは時間とともに最新版を指すように変わるため、バージョンを固定したい場合は`claude-opus-5-5`のような正式なモデル名を使ってください。
>
> 思考強度は `--effort low|medium|high|xhigh|max` で調整します。Opus 5.5 / Sonnet 5.5 / Haiku 5.5のデフォルトは `medium` です。

### 便利な起動オプション

```bash
# Plan Modeで開始（ファイル修正なしで計画のみ）
claude --permission-mode plan

# 毎回確認を求めるManualモードで開始（デフォルトはAutoモード）
claude --permission-mode manual

# 最初からセッションに名前を付ける
claude -n セッション名

# セッション名で引き継いで開始
claude --resume セッション名

# 以前の会話一覧から選んで引き継いで開始
claude --resume
```

> **ヒント**：最初はただ `claude` と入力して始めれば大丈夫です。残りは必要になったときに覚えても遅くありません。

## スラッシュコマンド（会話中に入力）

Claude Codeとの会話中に `/` で始まるコマンドを入力すると、特別な機能を使用できます。

### よく使うスラッシュコマンド

| コマンド | 説明 |
|--------|------|
| `/help` | 使用可能なコマンドの全リストを表示 |
| `/compact` | 会話内容を圧縮（長いセッションでは必須！） |
| `/clear` | 会話を初期化（完全にやり直し） |
| `/usage` | 現在のセッションのトークン使用量・コストとプラン使用量を確認（`/cost`、`/stats`は同じコマンドのエイリアス） |
| `/effort` | モデルの思考強度を調整（low/medium/high/xhigh/max） |
| `/model` | 使用中のAIモデルを変更 |
| `/fast` | Fast Modeのオン/オフ（Opusの応答速度が最大2.5倍、追加課金あり） |
| `/permissions` | 権限設定の確認と管理 |
| `/memory` | CLAUDE.mdの編集、自動メモリの確認/オン・オフ |
| `/quit` または `/exit` | Claude Codeを終了 |
| `/plan [説明]` | Plan Modeに切り替え（説明を付けると、その作業の計画をすぐ開始） |
| `/init` | プロジェクトにCLAUDE.mdファイルを生成 |
| `/doctor` | インストール・設定状態を診断 |
| `/theme` | カラーテーマの変更 |
| `/config` | 設定画面（エディタモード、自動アップデートチャンネル、テーマなど） |
| `/branch [名前]` | 現在の地点で会話を分岐（別の方向を試しても元の会話は残る） |
| `/fork` | 現在の会話をバックグラウンドセッションにコピーし、ここでは作業を継続 |
| `/rewind` | コードと会話を以前のチェックポイントに戻す（または一部の区間だけ要約） |
| `/context` | コンテキストウィンドウのトークン使用量を可視化 |
| `/rename [名前]` | セッションに名前を付ける（`--resume 名前`で再開） |
| `/resume [名前]` | 別のセッションに切り替え（名前指定または一覧から選択） |
| `/diff` | Claudeがこれまでに修正した内容を一覧でレビュー |
| `/export [ファイル名]` | 現在の会話をテキストとして書き出し |
| `/btw [質問]` | 会話に残さないちょっとした質問（コンテキストを消費しない） |
| `/goal` | ゴールを設定すると、条件を満たすまでClaudeが作業を続ける |
| `/subtask` | 付随タスクをサブエージェントに任せ、結果だけ受け取る |
| `/loop [間隔] [プロンプト]` | 同じプロンプトを定期的に繰り返し実行 |
| `/insights` | 最近のセッションを分析した使用パターンレポート（HTML）を生成 |
| `/release-notes` | バージョンごとの変更点を表示 |
| `/powerup` | 短いインタラクティブ講座で機能を学ぶ |
| `/bug` | Anthropicにバグレポートを直接送信 |

> `/vim` は削除されました。Vim編集モードは `/config` → Editor modeで有効にします。`/clone`、`/half-clone` のようなコマンドは存在しません。

### スラッシュコマンドの使い方

```
> /compact
→ 会話内容を要約してコンテキストを削減します

> /compact コード変更点を中心に整理して
→ 圧縮の方向を直接指定できます

> /model
→ モデル選択画面が表示されます
```

> **ヒント**：会話画面で `/` だけ入力すると、使用可能なコマンド一覧がオートコンプリートで表示されます。

## 会話の分岐と実験の戦略

会話の途中で方向を変えたり、リスクのある実験を安全に試したいときに活用できる機能です。

### `/branch` — 元の会話を保持したまま実験する

現在の地点で会話を分岐します。複雑なリファクタリングや構造的な変更を試す前に分岐しておけば、失敗してもそれまでの会話を失いません。

```
> /branch ストリーミング方式の実験
→ 現在の地点から新しい分岐を開始（名前を省略すると最初のプロンプトから自動命名）
→ 元の会話はそのまま残る → /resume 元の名前 で戻れる
```

**こんなときに使ってみてください**
- 複数の実装方法のうち1つをまず試してみたいとき
- 「こう直したらどうなるかな」と思うが失敗が心配なとき
- 同じ問題を異なるアプローチで比較してみたいとき

### `/fork` — コピーをバックグラウンドに渡す

現在の会話をバックグラウンドセッションにコピーし、いまのターミナルではそのまま作業を続けます。片方をバックグラウンドで走らせながら、別の方向を自分で進めたいときに便利です。

```
> /fork
→ 会話のコピーがバックグラウンドセッションへ移動
→ 現在のウィンドウではそのまま作業を継続
```

> 失敗した地点まで完全に巻き戻したい場合は`/rewind`（または入力欄が空の状態で`Esc`2回）を使います。メニューで**コード+会話 / 会話のみ / コードのみ**の巻き戻しを選ぶか、特定の地点以降（または以前）の会話だけを**要約**してコンテキストを空けることもできます。

### `/context` — コンテキスト使用量の確認

```
> /context
→ [■■■■■■■□□□] 70% (700,000 / 1,000,000 tokens)
```

現在の会話がコンテキストウィンドウの何%を占めているか視覚的に表示します。80%以上になったら`/compact`や`/clear`を検討してください。

> 現在のモデル（Fable 5.1 / Opus 5.5 / Sonnet 5.5 / Haiku 5.5）はすべて**100万（1M）トークン**のコンテキストです。上限に近づくと自動的に圧縮され、`/autocompact 500k` のように、より早く圧縮されるよう調整することもできます。

### `/rename` — セッションに名前を付ける

重要な作業セッションに名前を付けておくと、後から簡単に再開できます。

```
> /rename 競合調査-2月

# 後でターミナルから引き継いで開始
$ claude --resume 競合調査-2月
```

## キーボードショートカット

会話中にキー操作で素早く制御できます。

### 主要ショートカット

| ショートカット | 説明 |
|--------|------|
| `Ctrl+C` | 現在の作業をキャンセル（Claudeが何かしている途中で止めたいとき）。何も実行中でなければ入力欄をクリアし、もう一度押すと終了 |
| `Esc` | Claudeの応答・ツール実行を中断（それまでの作業は保持）、開いているダイアログを閉じる |
| `Ctrl+D` | Claude Codeを終了（2回押す） |
| `Ctrl+L` | 画面を再描画（表示が崩れたとき。会話内容は保持） |
| `Ctrl+R` | 以前入力したコマンドを検索 |
| `Ctrl+G` | 現在入力中の内容を外部テキストエディタで編集 |
| `Ctrl+O` | 詳細な記録（transcript）を表示 ── どのツールをどう使ったか確認 |
| `Ctrl+T` | ClaudeのToDoチェックリストの表示/非表示 |
| `Ctrl+S` | 作成中のプロンプトを一時的に退避 / 再び取り出す |
| `Ctrl+V`（Windows/WSLは `Alt+V`） | クリップボードの画像を貼り付け |

### 入力関連ショートカット

| ショートカット | 説明 |
|--------|------|
| `Shift+Enter` | 改行（長い指示を複数行で入力するとき。効かない場合は `/terminal-setup` を実行） |
| `Option+Enter`（macOS） | 改行（macOSデフォルト） |
| `\` + `Enter` | 改行（すべてのターミナルで動作） |
| `↑` / `↓` 矢印キー | 前/次のコマンドを参照 |
| `Esc` + `Esc`（2回） | 入力欄が空なら巻き戻しメニュー、文字があれば入力をクリア |
| `@` | ファイルパスのオートコンプリート（`@ファイル名`でファイルを会話に渡す） |
| `!`（先頭） | シェルコマンドを直接実行し、結果を会話に追加 |
| `?`（空の入力欄で） | ショートカットのヘルプパネルのオン/オフ |

### モード切り替えショートカット

| ショートカット | 説明 |
|--------|------|
| `Shift+Tab` | 権限モードを順番に切り替え（Auto → Manual → Accept Edits → Plan → Auto） |
| `Option+P`（macOS） / `Alt+P` | モデル変更 |
| `Option+O`（macOS） / `Alt+O` | Fast Modeのオン/オフ |
| `Option+T`（macOS） / `Alt+T` | 拡張思考モードのオン/オフ（Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fableは常にオンのため効果なし） |
| `Ctrl+B` | 実行中のコマンド・エージェントをバックグラウンドに送って会話を続ける |
| `Ctrl+X` の後に `Ctrl+K` | バックグラウンドのサブエージェントをすべて停止（3秒以内に2回） |

## 初心者がよく使うコマンドTOP 5

始めたばかりなら、この5つだけ覚えれば十分です。

### 1. `/compact` — 最も重要なコマンド

```
> /compact
```

会話が長くなると、Claudeが遅くなったり古い内容を忘れたりします。このとき `/compact` と入力すると会話を圧縮して速度を回復します。**長い作業中は定期的に使う習慣をつけましょう。**

### 2. `Ctrl+C` — 止めたいとき

Claudeが見当違いの方向に進んでいるとき、または誤って危険なコマンドを許可してしまったときに即座に停止します。

### 3. `/clear` — 最初からやり直すとき

```
> /clear
```

まったく別のトピックに移るときに使います。以前の会話内容はすべて消去されます。

### 4. `Shift+Enter` — 長い指示の入力

1行で書ききれない長いリクエストは `Shift+Enter` で改行しながら入力してください。

```
（Shift+Enterで複数行入力の例）
ログインページを作って。
- メールアドレスとパスワードのフィールド
- パスワードの表示/非表示ボタン
- ログインボタン（ローディング状態付き）
```

### 5. `/usage` — 使用量・コスト確認

```
> /usage
```

現在のセッションでどれくらい使ったか確認します。（`/cost`と`/stats`は同じコマンドのエイリアス。サブスクリプションユーザーにはプラン使用量のバーと、どのスキル・サブエージェント・MCPサーバーが使用量を多く占めたかも合わせて表示されます）

> 使用量の上限に達したら `/rate-limit-options` で選択肢を確認できます。上限が解除されるまで待って自動的に作業を再開させるか、`/usage-credits` で追加使用量（usage credits）を有効にできます。

<details>
<summary>🖥️ 開発者向け：ターミナルAlias設定（ショートカットコマンド）</summary>

毎回長いコマンドを入力する代わりに、短いaliasを登録しておくとずっと便利です。

### macOS / Linux（zsh）

`~/.zshrc` ファイルに追加：

```bash
alias cc='claude'
alias ccd='claude --dangerously-skip-permissions'
alias ccr='claude --resume --dangerously-skip-permissions'
```

追加後に適用：

```bash
source ~/.zshrc
```

### Windows（PowerShell）

`$PROFILE` ファイルに追加：

```powershell
function cc { claude @args }
function ccd { claude --dangerously-skip-permissions @args }
function ccr { claude --resume --dangerously-skip-permissions @args }
```

PowerShellを再起動すると適用されます。

### 各Aliasの説明

| コマンド | 意味 | 使用タイミング |
|--------|------|----------|
| `cc` | 基本実行 | 常時 |
| `ccd` | 権限確認を自動承認 | 信頼できるプロジェクト、素早い作業 |
| `ccr` | 前回のセッション再開 + 権限自動承認 | 昨日の作業の続き |

> ⚠️ **注意**：`--dangerously-skip-permissions`はファイル修正、コマンド実行などすべての権限確認を自動的に承認します。自分で作ったプロジェクト、信頼できる環境でのみ使用してください。
>
> 💡 現在はセッションがデフォルトで**Autoモード**（分類器が審査し、ほとんど確認ダイアログなしで進行）で開始するため、`ccd` のようなaliasが本当に必要な場面は多くありません。隔離されたコンテナでなければ、`--permission-mode auto` を使う方が安全です。

</details>
